GenAI Term Project · Fall 2026 · Proposal

長庚大小事 LINE BotWhat's UP! — a self-updating multilingual LINE bot for CGU

讓長庚大學的外籍學生，用自己的母語在 LINE 上問「學校大小事」。系統每天自動爬取校方公告建立 RAG 知識庫；答不出來的問題會開成 Ticket，由 AI 代理補資料、驗證正確性，經使用者回饋後才進入正式知識庫。 Let international students at Chang Gung University ask anything about campus life on LINE, in their own language. The system crawls official CGU announcements daily into a RAG knowledge base; unanswered questions become tickets that an AI agent researches and verifies, and answers only enter the production knowledge base after user feedback.

目標問題（輸入／輸出定義）Target Problem (input / output)

將問題定義為一個 多語、可持續更新、具可信度控管的檢索增強生成（RAG）問答任務。We frame it as a multilingual, continuously updated, trust-controlled Retrieval-Augmented Generation (RAG) question-answering task.

Input

  • 使用者在 LINE 上以任意語言輸入的自然語言問題A natural-language question in any language, sent on LINE
  • 對話脈絡（同一使用者的前幾輪）Conversation context (previous turns of the same user)
  • 知識庫：長庚官網公告、處室頁面、規章、行事曆（中／英文）Knowledge base: CGU announcements, office pages, regulations, academic calendar (Chinese / English)
→

Output

  • 以使用者語言回覆的答案 + 官方來源連結 + 資料日期An answer in the user's language + official source link + data date
  • 或：信心不足時誠實告知，並建立 Ticket，稍後主動推播答案Or, when confidence is low: an honest "not sure yet", a ticket, and a push message later with the answer
  • 系統面：一筆經驗證、帶來源的新知識條目System side: a new, verified knowledge entry with its source

限制條件：答案必須可追溯到官方來源；不可捏造日期、金額、規定；高風險資訊需標示「請以官方公告為準」。Constraints: every answer must trace back to an official source; no fabricated dates, amounts or rules; high-risk information carries a "refer to the official notice" disclaimer.

我們的做法（四步）Our approach (four steps)
  1. 一次改寫：原文＋詞彙表 → LLM 輸出繁中版、英文版。One-hop rewrite: original + glossary → LLM outputs zh-TW and English versions.
  2. 三路檢索：繁中 BM25（jieba 斷詞）＋ 繁中／英文向量檢索 ＋ 原文向量檢索（翻譯出錯時的保險）。Three-way retrieval: zh-TW BM25 (jieba tokenized) + zh-TW / English dense retrieval + original-query dense retrieval (a safety net for bad translations).
  3. RRF 融合 + 重排：Reciprocal Rank Fusion 合併排名，再用 bge-reranker 重排。RRF fusion + rerank: merge rankings with Reciprocal Rank Fusion, then rerank with bge-reranker.
  4. 文件端配合：中文原文＋LLM 產生的英文摘要一起建索引。Document side: index the Chinese original together with the LLM-written English summary.

晉升規則（建議修正版）Promotion rules (recommended revision)

👍 有讚Thumbs-up

至少 1 個讚且沒有倒讚 → 晉升正式庫。At least one 👍 and no 👎 → promote to Production.

👎 倒讚Thumbs-down

附上使用者意見重開 Ticket，該條目暫停被檢索。Re-open the ticket with the user's comment and stop retrieving the entry.

⏳ 沒有回應No response

7 天後，且驗證分數 ≥ 0.8、且有官方來源連結 → 晉升。簽證、居留證、學費、獎學金、畢業等高風險類別一律需人工核可。After 7 days, and a judge score ≥ 0.8, and an official source link → promote. High-risk categories (visa, residence permit, tuition, scholarships, graduation) always need human approval.

為什麼要修正：沉默可能代表使用者沒看到，不代表答案正確；把「AI 驗證分數」與「來源可信度」加進來，可以在不增加太多人力的情況下控制錯誤擴散，這也是報告中可以討論的技術亮點。Why revise: silence may mean the user never read the reply, not that it was right. Adding the judge score and source credibility limits error propagation without much extra human effort — and it's a technical point worth discussing in the report.

11

風險與倫理Risks & Ethics

幻覺與錯誤資訊Hallucination & misinformation

只依檢索內容回答、強制附來源、信心不足就開 Ticket；高風險類別加註「以官方公告為準」並需人工核可。Answer only from retrieved context, always cite, open a ticket when unsure; high-risk categories carry a disclaimer and need human approval.

隱私Privacy

只保存 LINE userId 的雜湊值與問題文字；不蒐集姓名、學號；提供刪除紀錄的指令；福祉相關訊息不寫入知識庫。Store only a hashed LINE userId and question text; no names or student IDs; offer a delete-my-data command; wellbeing messages never enter the KB.

爬蟲禮儀與著作權Crawler etiquette & copyright

遵守 robots.txt、限速、只爬公開頁面；回答時引用並導回原網頁；正式上線前可與國際處溝通合作。Respect robots.txt, rate-limit, crawl public pages only; cite and link back to the original page; talk to the international office before any real launch.

心理健康界線Mental-health boundaries

Bot 不提供診斷或諮商，只做資訊轉介；偵測到危機訊號時提供校內輔導與緊急求助資訊。The bot never diagnoses or counsels; it only refers. On crisis cues it shares campus counseling and emergency contacts.

成本Cost

日常問答用小模型、驗證用較強模型；快取常見問題；LINE 免費方案每月推播則數有限，推播僅用於 Ticket 結果。Small models for routine Q&A, a stronger model for verification; cache frequent questions; LINE's free plan caps monthly push messages, so pushes are used only for ticket results.

回饋被濫用Feedback abuse

單一使用者的讚不足以讓高風險內容晉升；異常大量倒讚會觸發人工檢查。One user's 👍 cannot promote high-risk content; unusual bursts of 👎 trigger a human check.
