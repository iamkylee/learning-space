Part 1

機率是什麼？What is Probability?

「這枚硬幣出現正面的機率是 0.5」這句話到底在說什麼？歷史上有兩種主要的詮釋：

Frequentist

頻率學派Frequentist interpretation

機率是長期相對頻率long-run relative frequency。把同一個實驗重複無限多次，某結果出現的比例會收斂到一個固定值，那個值就是機率。

機率是「世界的客觀性質」。

Bayesian

貝氏學派Bayesian interpretation

機率是信念的程度degree of belief。它描述一個觀察者在目前資訊下，有多相信某件事會發生，並且會隨著新的證據evidence更新。

機率是「觀察者腦中的模型」。

為什麼這很重要
影片採用的是貝氏觀點：機率住在觀察者的腦袋裡。這個觀點是後面的關鍵，因為一旦機率是「某個人的信念」，就可能出現信念和現實不一致的情況：世界照著分布 P 運作，觀察者卻相信自己的內部模型internal model Q。交叉熵與 KL 散度，正是在量化這種落差。

貝氏學派常用的幾個詞彙先列在這裡：先驗prior（看到資料前的信念）、概似 / 似然likelihood（在某假設下看到這筆資料的機率）、後驗posterior（看到資料後更新過的信念）。

想像擲很多次：大多數是正面或反面（各約 1.03 bits 的驚訝），偶爾出現一次側立（5.64 bits 的大驚訝）。把整串驚訝度平均起來：

熵的三種讀法

  • 平均驚訝度average surprise：影片的定義。
  • 不確定性uncertainty：分布越「攤平」越難預測，熵越高；越集中越好猜，熵越低。
  • 最短平均編碼長度optimal average code length：根據夏農信源編碼定理Shannon's source coding theorem，要無損地傳送這個隨機變數的結果，平均每個結果至少需要 個 bits。常見結果用短碼，罕見結果用長碼，最佳碼長正好是 。

重要性質

  • ，而且只有在某個結果機率為 1（確定性分布deterministic）時才等於 0。
  • 有 個狀態時，熵最大是 ，發生在均勻分布uniform distribution。公平骰子： bits。
  • 約定 ：從不發生的事不會貢獻任何平均驚訝。

吉布斯不等式Gibbs' inequality保證：

直覺上，不管你相信什麼模型，平均驚訝度都不可能低於「完全知道真相」的情況。真實分布本身的熵，是驚訝度的最低可能值。

延續硬幣例子
真實 P = (0.49, 0.02, 0.49)。假如觀察者完全不懂硬幣，認為三種結果一樣可能 Q = (1/3, 1/3, 1/3)。那每次觀察的驚訝都是 ，所以 bits，比真正的熵 1.12 bits 多了約 0.46 bits。
危險：模型說不可能的事
如果某個狀態真的會發生（），模型卻給它 ，驚訝度就是 ，交叉熵直接爆掉。這是為什麼機器學習模型通常不讓機率剛好等於 0（例如用 softmax 輸出，或加上很小的 ε）。

編碼角度的解釋：交叉熵是用為 Q 設計的最佳編碼，去傳送其實來自 P 的資料時，平均需要的 bits 數。

Part 6

KL 散度：只屬於「模型錯誤」的那份驚訝KL-Divergence — isolating the surprise caused by model mismatch

交叉熵裡其實混了兩種驚訝：

  1. 世界本身就有隨機性，就算模型完美也躲不掉的驚訝：。
  2. 因為模型 Q 和現實 P 不一致而多出來的驚訝。

把第 1 種扣掉，剩下的就是KL 散度Kullback–Leibler divergence，也叫相對熵relative entropy：

影片寫成 ，教科書多寫 ，讀作「P 相對於 Q 的 KL 散度」。兩者意思相同。

三者的關係

性質

  • 非負non-negative：，只有 P = Q 時等於 0（就是吉布斯不等式）。
  • 不對稱asymmetric：。
  • 因此它不是真正的距離not a metric / distance：不對稱，也不滿足三角不等式triangle inequality。所以叫「散度」divergence而不叫「距離」。
  • 硬幣例子： bits，就是剛剛「多出來的 0.46 bits」。

方向的意義：正向 vs 反向 KL

Forward KL

，正向 KLforward KL

只要 P 有機率的地方，Q 就不能是 0，否則無限大。所以最小化它時，Q 傾向攤開蓋住所有可能：涵蓋眾數mode-covering。

Reverse KL

，反向 KLreverse KL

權重來自 Q，所以 Q 可以放心忽略 P 的某些區域，只專心貼合其中一個高峰：尋找眾數mode-seeking。變分推論variational inference常用這個方向。

Part 8

總整理Summary

Surprise驚訝度

How surprised you are to see one outcome.
看到單一結果的驚訝程度。

Entropy熵

Average surprise packed into the distribution.
分布本身平均蘊含的驚訝度。

Cross-entropy交叉熵

Total surprise observing one distribution, while believing in a different internal model.
觀察某個分布、心裡卻相信另一個內部模型時的平均驚訝度。

KL-divergenceKL 散度

Isolating the surprise caused by the discrepancy between the model and the true distribution.
單獨抽出「模型與真實分布不一致」所造成的那部分驚訝。

一條線串起來：機率 → 取 log 得到驚訝度 → 依真實分布平均得到熵 → 改用錯誤模型的驚訝得到交叉熵 → 扣掉熵得到 KL 散度 → 最小化交叉熵就是學習。
