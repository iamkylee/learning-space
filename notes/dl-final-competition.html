糖尿病視網膜病變分級競賽：團隊說明Diabetic Retinopathy Grading: Team Briefing

整理自課程簡報〈DL competition 2026〉與官方程式碼 competition2026。說明比賽目標、資料、基準程式如何運作、怎麼提交，以及我們可以從哪裡提升分數。A summary of the course slides “DL competition 2026” and the official competition2026 code: the goal, the data, how the baseline works, how to submit, and where we can gain score.

比賽在做什麼What the competition asks

輸入一張視網膜眼底照片，模型要輸出 5 個糖尿病視網膜病變（DR）嚴重程度之一。這是一個 5 類影像分類 問題，評分指標是 準確率（accuracy）。Given one retinal fundus photo, the model outputs one of five diabetic retinopathy (DR) severity grades. It is a 5-class image classification task scored by plain accuracy.

簡報特別提醒The slides stress this 訓練集只有 16 張「輕度」，但有 107 張「無病變」。模型可能整體準確率不錯，卻幾乎抓不到輕度病例。The training set has only 16 mild cases against 107 no-DR images. A model can post good overall accuracy while still missing almost every mild case.

The data is pre-split into train and val, with one sub-folder per grade.

1. 前處理（Transforms）1. Pre-processing (transforms)

訓練集用資料增強（隨機水平/垂直翻轉、±20° 旋轉、亮度與對比 ±0.2），讓模型看到更多變化；驗證/測試集只做縮放與正規化，保持結果穩定。正規化用的是 ImageNet 的平均值與標準差。The training set gets augmentation (random horizontal/vertical flips, ±20° rotation, ±0.2 brightness and contrast) for variety; val/test only resize and normalize so results are deterministic. Normalization uses ImageNet mean and std.

transforms.Resize((512, 512))
transforms.Normalize((0.485, 0.456, 0.406), (0.229, 0.224, 0.225))

2. 模型結構2. Model

一個從零訓練的小型 CNN：三個「Conv 3×3 → ReLU → MaxPool」區塊（通道 3→32→64→128），接著攤平後經過兩層全連接層輸出 5 類分數。A small CNN trained from scratch: three “Conv 3×3 → ReLU → MaxPool” blocks (channels 3→32→64→128), then flatten and two fully connected layers that output 5 class scores.

觀察Observation全部約 6,720 萬個參數，其中 99.9% 在第一層全連接層。用 329 張圖訓練這麼大的全連接層非常容易過擬合，這是我們最容易改進的地方。About 67.2M parameters in total, 99.9% of them in the first fully connected layer. Training a layer that size on 329 images overfits easily, which makes it the most obvious thing to improve.

3. 訓練與驗證3. Training and validation

  • 損失函數 CrossEntropyLoss，優化器 SGD（lr = 0.01，無 momentum），50 個 epoch。CrossEntropyLoss, SGD optimizer (lr = 0.01, no momentum), 50 epochs.
  • 每個 epoch：model.train() → 前向 → 反向傳播 → 更新權重；再 model.eval() + torch.no_grad() 計算 val 準確率。Each epoch: model.train() → forward → backward → step; then model.eval() + torch.no_grad() to compute val accuracy.
  • val 準確率創新高時，用 copy.deepcopy 保存權重；結束後載回最佳權重並匯出 TorchScript。When val accuracy hits a new best, the weights are saved with copy.deepcopy; at the end the best weights are reloaded and exported to TorchScript.

4. 評估4. Evaluation

python evaluate.py idrid_model.pth training   # val set → {"total":84,"correct":..,"accuracy":..}
python evaluate.py idrid_model.pth hidden     # hidden test set (graders only)

evaluate.py 用 torch.jit.load 載入模型，所以 不需要你的 Python 類別定義，但模型必須能被 TorchScript 轉換。evaluate.py loads the model with torch.jit.load, so it does not need your Python class, but the model must be convertible to TorchScript.

容易出錯的地方Gotchas

  • 輸入格式被評分程式固定。evaluate.py 會把圖縮到 512×512 並用 ImageNet 正規化後才餵給模型。若想用其他解析度（例如 384 或 768），最安全的做法是把 F.interpolate 寫進模型的 forward 裡，而不是改 evaluate.py。The grader fixes the input. evaluate.py resizes to 512×512 and applies ImageNet normalization before calling the model. To use another resolution (say 384 or 768), the safe route is an F.interpolate inside the model’s forward, not editing evaluate.py.
  • 必須能 torch.jit.script。torchvision 內建模型（ResNet、EfficientNet、ConvNeXt 等）都可以；自己寫的模型避免動態 Python 型別或不支援的語法。匯出前請先在本機跑一次 evaluate.py。It must pass torch.jit.script. torchvision models (ResNet, EfficientNet, ConvNeXt …) work; for custom code avoid dynamic Python typing and unsupported syntax. Run evaluate.py locally before uploading.
  • 匯出時移到 CPU。基準程式用 model.to("cpu") 再 script，評分端才能在任何裝置上載入。Export on CPU. The baseline calls model.to("cpu") before scripting so the grader can load it on any device.
  • 輸出要是 5 個 logits。評分用 torch.max(outputs, 1) 取類別，所以 forward 只能回傳形狀 [B, 5] 的張量，索引順序依 class_to_idx.txt。Return 5 logits. The grader takes torch.max(outputs, 1), so forward must return a [B, 5] tensor in class_to_idx.txt order.
  • val 只有 84 張。1 張圖 ≈ 1.19 個百分點，分數波動很大；比較模型時可以用多個 seed 或交叉驗證。Val is only 84 images. One image ≈ 1.19 percentage points, so scores are noisy; compare models over several seeds or with cross-validation.

可以從哪裡提升分數Where to gain score

依預期效果大致排序。這些是建議起點，需要實驗驗證。Roughly ordered by expected payoff. These are starting points to test, not guarantees.

使用預訓練模型Use a pretrained backbonehigh

torchvision 的 ResNet / EfficientNet / ConvNeXt 用 ImageNet 權重做遷移學習，通常比從零訓練好很多，而且輸入正規化剛好與評分程式一致。Fine-tune torchvision ResNet / EfficientNet / ConvNeXt with ImageNet weights. Usually far better than training from scratch, and the input normalization already matches the grader.

處理類別不平衡Handle class imbalancehigh

類別加權的 CrossEntropy、WeightedRandomSampler 或 focal loss，讓輕度病例不被忽略。Class-weighted CrossEntropy, a WeightedRandomSampler, or focal loss so mild cases are not ignored.

更好的優化設定Better optimizationhigh

AdamW + cosine 學習率排程 + warmup；搭配 early stopping 或保留最佳權重。AdamW with a cosine schedule and warmup; keep early stopping or best-weight saving.

眼底影像專用前處理Fundus-specific preprocessingmid

裁掉黑邊、調整對比；但評分端只做 resize + normalize，所以任何前處理都要放進模型 forward 或只用在訓練增強。Crop black borders, boost contrast. The grader only resizes and normalizes, so any preprocessing must live inside forward or be used only as training augmentation.

利用等級的順序性Use the ordinal labelsmid

等級 0–4 有順序，可試 label smoothing、回歸頭再四捨五入，或順序型損失；輸出仍需轉成 5 個分數。Grades 0–4 are ordered: try label smoothing, a regression head with rounding, or an ordinal loss. Output must still be 5 scores.

集成與 TTAEnsembles and TTAmid

把多個模型或翻轉後的預測平均，包成一個 TorchScript 模組就能直接提交。Average several models or flipped predictions and wrap them in one TorchScript module to submit.

最後用 train + val 一起訓練Final fit on train + vallow

設定定案後，用全部 413 張重訓一次，再提交給測試集。Once settings are fixed, retrain on all 413 images before the test-set submission.
