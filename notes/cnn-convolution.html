CNN 卷積筆記

從一張圖怎麼一層層變成分類結果開始，整理卷積、感受野、參數量、輸出尺寸、Pooling、BatchNorm、反卷積和經典架構。每一節都有例子和圖，最後有可以自己組網路的計算器和練習題。

第一部　基礎
01 · Overview

CNN 全貌：一張圖怎麼變成答案

CNN 把影像當成一個 高 × 寬 × 通道 的立方體。每經過一層，立方體的形狀就改變一次：卷積通常讓通道變多，Pooling 讓高寬變小，最後攤平或做全域平均，接全連接層輸出各類別分數。

典型的層順序：

輸入 → [卷積 → BN → ReLU] × n → Pooling → [卷積 → BN → ReLU] × n → Pooling → … → GAP 或攤平 → 全連接 → Softmax
層改變什麼有沒有參數
卷積通道數（通常變多），stride > 1 時高寬變小有，k²·Cin·Cout
激活（ReLU）只改數值，形狀不變沒有
Pooling高寬變小，通道不變沒有
BatchNorm只改數值，形狀不變有，每通道 γ、β
反卷積高寬變大有，和卷積一樣
全連接把向量映射成另一個長度的向量有，輸入 × 輸出
卷積加通道、Pooling 縮高寬、最後接全連接出答案；每一層的形狀都能用公式算出來。
02 · Convolution

卷積運算：對應相乘，再全部加起來

把 kernel 蓋在輸入上，對應位置相乘後相加，得到輸出的一個數字。接著依 stride 往右、往下移動，重複同樣的動作。下面這個 kernel 會偵測「左亮右暗」的垂直邊緣。

多通道：kernel 也有深度

彩色圖有 3 個通道。一個 kernel 的大小其實是 k × k × C_in，它同時覆蓋所有輸入通道，相乘加總後只產生一張輸出特徵圖。想要 C_out 張輸出，就準備 C_out 個 kernel。

一個 kernel： k × k × C_in 個權重 + 1 個 bias 整層： C_out 個 kernel 參數量 = k² × C_in × C_out (+ C_out) 例：5×5×3×6 + 6 = 456
一個 kernel 吃掉全部輸入通道、吐出一張特徵圖；輸出有幾個通道，就有幾個 kernel。
03 · Receptive field

感受野：輸出的一個點，往回看到多大範圍

感受野是層層累積的。第二層的 3×3 看第一層的 3 個點，但第一層的每個點本身又看了輸入的 3 個點，而且彼此重疊。所以不是 3，也不是 9，而是 5。

輸入:     [1][2][3][4][5]
第一層:      [a][b][c]      a 看 1,2,3；b 看 2,3,4；c 看 3,4,5
第二層:         [x]         x 看 a,b,c → 間接看到 1~5，共 5 格

二維也一樣：中央 3×3 往上下左右各多推出 1 格，3 + 1 + 1 = 5。每多一層 3×3（stride 1），邊長多 2。

stride 全為 1： RF = 1 + n × (k − 1) 各層 kernel 不同： RF = 1 + (k₁−1) + (k₂−1) + … + (kₙ−1) 有 stride： RF = 1 + Σ (kᵢ − 1) × (前面所有層 stride 的乘積) 有膨脹 d： 把 (k − 1) 換成 d × (k − 1) Pooling 也算： 用它的 k 和 s 一起代進去
情況計算RF
1 層 3×31 + 1×23
2 層 3×31 + 2×25
3 層 3×31 + 3×27
3×3 → 5×5 → 7×71 + 2 + 4 + 613
3×3 s2，再 3×3 s11 + 2×1 + 2×27
3×3，2×2 池化 s2，3×31 + 2 + 1×1 + 2×28
每多一層 kernel k，感受野多長 (k−1)；前面有 stride 就再乘上 stride 的累積乘積。
04 · Parameters

參數量：小核疊起來比較省

單層 k×k 卷積：params = k × k × C_in × C_out (+ C_out 個 bias) 輸入輸出都是 C：params = k² × C²
同樣感受野一層大核多層 3×3省下
5×5 vs 兩層 3×325C²18C²28%
7×7 vs 三層 3×349C²27C²45%

原題回顧：為什麼答案是 B

  • 感受野相同：兩層 3×3 = 5×5。（A 說只有 3×3，錯）
  • 表達力更強：單一 5×5 是一次線性運算；兩層中間夾 ReLU，可以「先偵測邊緣，再組合成角落」。（C 說會算出相同函數，錯）
  • 參數更少：18C² < 25C²。（C 說更多，錯）
  • 不需要 stride：stride 1 疊兩層就已經是 5×5。（D 錯）
小核疊起來：看得一樣遠、算得更複雜、花得更少。這是 VGG 之後大家愛用 3×3 的原因。
第二部　尺寸計算
05 · Output size

輸出尺寸：窗戶能放幾個位置

輸出 = ⌊ (輸入 − k + 2p) / s ⌋ + 1
  1. 窗戶（kernel）放在最左邊，佔 k 格。
  2. 可往右滑的距離是 輸入 + 2p − k。
  3. 每次跳 s 格，能跳 ⌊距離 / s⌋ 次，剩下不夠跳的捨去。
  4. 再加上起始位置那 1 個。

為什麼是 2p？padding 是「每一邊」補的格數。一維有前後兩端，二維的寬有左右、高有上下，所以總共多 2p 格。64 補 p=1 會變成 66。

補之前:  [1 2 3 … 64]            → 64 格
補之後:  [0][1 2 3 … 64][0]      → 1 + 64 + 1 = 66 格
一維卷積示意點輸出格，看它用到哪些輸入
padding（補 0）這個輸出用到的輸入選中的輸出

k′ 是有效 kernel，說明在 06 膨脹卷積。池化也用同一個公式（膨脹填 1）。想整個網路一層層算，請到 逐層實作。

輸入 64，設定輸出用途
k=3, s=2, p=031不補邊
k=3, s=2, p=132剛好減半，常用的下採樣
k=3, s=1, p=164尺寸不變
k=3, s=1, p=062每層少 2

有些框架允許兩邊補不一樣多（TensorFlow 的 same 在總補數為奇數時右下多補 1 格），這時 2p 要換成「前補 + 後補」的實際總和。

k=3、p=1 時，stride 1 保持大小，stride 2 剛好減半。
06 · Dilation

膨脹卷積：權重不變，看得更遠

在 kernel 的格子之間插入空隙。仍然只有 k 個權重，但涵蓋範圍變大。

d=1:  ● ● ●          → 涵蓋 3 格
d=2:  ● _ ● _ ●      → 涵蓋 5 格
d=3:  ● _ _ ● _ _ ●  → 涵蓋 7 格
有效 kernel k′ = d × (k − 1) + 1 輸出 = ⌊ (輸入 − k′ + 2p) / s ⌋ + 1

算法和一般卷積一樣，只是把 k 換成 k′。d = 1 時 k′ = k，一般卷積是膨脹卷積的特例。

07 · Kernel vs stride

kernel 是窗戶大小，stride 是每次挪幾步

兩者是獨立的設定。YOLO 說的「stride 32」是整個網路的總縮小倍數，由多次 stride 2 累積出來，不是第一層就跳 32，kernel 通常還是 3×3。

設定合理嗎
3×3、stride 2，重複 5 次合理：逐步縮小，資訊逐層整合
3×3、stride 32，一次完成不合理：每次看 3 格卻跳 32 格，中間 29 格漏看
32×32、stride 32可行但只有一層。ViT 的 patch embedding 就是 kernel = stride（如 16×16）
第三部　各種層
08 · Activation

激活函數：沒有它，疊再多層都只是一層

卷積是線性運算。兩個線性運算接在一起還是線性：兩層沒有激活的 3×3，數學上就等於一層 5×5。中間插入非線性函數，網路才能學到彎曲、組合式的規則。這正是原題 B 選項說「能表示單層做不到的函數」的原因。

函數公式特性
ReLUmax(0, x)最常用，計算快；負值全變 0
Leaky ReLUx ≥ 0 ? x : 0.01x負值保留一點斜率，避免神經元「死掉」
Sigmoid1 / (1 + e⁻ˣ)輸出 0～1，常用在二分類輸出；深層易梯度消失
Tanh(eˣ − e⁻ˣ)/(eˣ + e⁻ˣ)輸出 −1～1
SiLU / Swishx · sigmoid(x)YOLOv5 以後常用，平滑版 ReLU

激活函數沒有參數（PReLU 例外，每通道學一個斜率），形狀也不變，所以計算尺寸和參數量時可以直接略過。

激活不改形狀、不加參數，但讓「疊很多層」真正有意義。
09 · Pooling

Pooling：把一小塊濃縮成一個數

Pooling 也是一個滑動的窗戶，但不做乘法加總，而是取最大值（Max）或平均（Average）。最常見的是 2×2、stride 2，高寬減半。

輸出尺寸 = ⌊ (輸入 − k + 2p) / s ⌋ + 1 ← 和卷積同一個公式 通道數 = 不變（每個通道各自做） 參數量 = 0
設定例子輸出
2×2, s=232×32×6416×16×64
3×3, s=2, p=1（ResNet 開頭）112×112×6456×56×64
3×3, s=2, p=0（AlexNet）55×55×9627×27×96

Max 和 Average 怎麼選

  • Max pooling：保留最強的反應，小位移時結果不變，中間層最常用。
  • Average pooling：保留整體強度，比較平滑。
  • Global Average Pooling（GAP）：窗戶等於整張圖，每個通道平均成 1 個數，7×7×512 → 1×1×512，用在分類器最後。
  • 現代網路常用 stride 2 的卷積取代 pooling 下採樣（例如 YOLO、ResNet 的部分層），因為卷積可以學。
Pooling 用卷積的尺寸公式、通道不變、沒有參數。
10 · Batch normalization

BatchNorm：把每個通道拉回同樣的尺度

訓練時，每一層的輸入分布一直在變，網路難以穩定學習。BatchNorm 在每個通道上，把一個 batch 內的值標準化成平均 0、變異數 1，再用兩個可學的參數 γ、β 調回模型想要的尺度。

μ = (1/m) Σ xᵢ ← 這個通道在 batch 裡的平均 σ² = (1/m) Σ (xᵢ − μ)² ← 變異數 x̂ᵢ = (xᵢ − μ) / √(σ² + ε) ← 標準化，ε 防止除以 0 yᵢ = γ · x̂ᵢ + β ← 可學的縮放與平移 m = N × H × W（batch 大小 × 高 × 寬）

算一次看看

某通道在 batch 裡的值是 [2, 4, 6, 8]，γ = 2、β = 1，ε 忽略：

步驟計算結果
平均 μ(2+4+6+8)/45
變異數 σ²(9+1+1+9)/45
標準化 x̂(x − 5)/√5[−1.34, −0.45, 0.45, 1.34]
輸出 y2·x̂ + 1[−1.68, 0.11, 1.89, 3.68]

參數量

項目數量會被訓練嗎
γ（縮放）C會
β（平移）C會
running meanC不會，訓練時用移動平均累積
running varC不會

例如 64 通道的 BN：可訓練參數 128 個，另外存 128 個統計值。形狀不變。

訓練和推論不一樣

  • 訓練：用當下這個 batch 的 μ、σ²，同時更新 running mean / var。
  • 推論：改用 running mean / var，結果不會因為 batch 裡有哪些圖而改變。PyTorch 要記得 model.eval()。
  • batch 太小（例如 2）時統計值不穩，偵測和分割任務常改用 GroupNorm。

推論時融合進卷積

推論時 μ、σ²、γ、β 都是常數，BN 只是一個線性變換，可以直接併進前一層卷積的權重：

W′ = γ / √(σ² + ε) · W b′ = γ · (b − μ) / √(σ² + ε) + β

所以卷積後面接 BN 時，卷積通常設 bias=False，因為 bias 會被 BN 的平均抵消，由 β 取代。

BN 每通道有 γ、β 兩個可學參數；訓練用 batch 統計，推論用累積統計，還能併進卷積。
11 · Transposed convolution

反卷積：把特徵圖放大

反卷積（transposed convolution，也叫轉置卷積）是卷積的「反方向」：讓高寬變大，用在語意分割、生成模型、U-Net 的解碼器。它只把形狀反過來，不會把卷積前的數值還原，權重和一般卷積一樣是學出來的。

方向例子（k=3, s=2, p=1）
卷積大 → 小6 → 3
反卷積小 → 大3 → 6（op=1）

看法一：蓋印章

一般卷積是「看一塊、算出一個數」。反卷積反過來，是「拿一個數，蓋出一整塊」：

  1. 輸入的每一格，把整個 kernel 乘上自己的值，當成一個印章。
  2. 第 i 格的印章蓋在位置 i × s 開始的地方，所以每格往右移 s 格。
  3. 蓋到重疊的位置就相加。
輸入 [1, 2]，kernel [1, 2, 3]，stride 2，padding 0

位置:        0   1   2   3   4
輸入 1 蓋:   1   2   3              ← 1 × [1,2,3]，從位置 0 開始
輸入 2 蓋:           2   4   6      ← 2 × [1,2,3]，從位置 2 開始
─────────────────────────────
輸出:        1   2   5   4   6      ← 位置 2 重疊：3 + 2 = 5
蓋印章示意（一維）點「合計」或「輸出」的格子，看它是哪些印章加起來的
印章蓋下去的值 被 padding 剪掉 / output_padding 補的 最後的輸出

輸出長度的公式怎麼來的

  1. 最後一格輸入（第 in − 1 格）的印章從位置 (in − 1) × s 開始。
  2. 印章本身再往右延伸 k − 1 格。
  3. 所以最右邊在 (in − 1) × s + (k − 1)，長度要再 +1。
蓋完印章的全長 = (in − 1) × s + (k − 1) + 1 例：(2 − 1) × 2 + (3 − 1) + 1 = 5

再把其他三個設定加進來：

設定在反卷積裡的意思對公式的影響
padding p蓋完之後，頭尾各剪掉 p 格− 2p
膨脹 d印章的格子間有空隙，變寬成 d(k−1)+1 格(k−1) 換成 d(k−1)
output_padding尾端多保留幾格+ op
輸出 = (輸入 − 1) × s − 2p + d × (k − 1) + output_padding + 1 常用：k=4, s=2, p=1 → (in−1)×2 − 2 + 3 + 1 = 2 × in，剛好放大 2 倍 k=3, s=2, p=1, output_padding=1 → 也是 2 倍

為什麼 padding 是減的？反卷積是卷積的反方向。卷積的 padding 讓輸出變大，所以反卷積的 padding 意思也反過來，變成剪掉。這樣設計，設定相同的卷積和反卷積，形狀剛好互相對應：卷積 6 → 3，反卷積 3 → 6。

看法二：插 0，再做一般卷積

同一件事換一種算法，結果完全一樣。下面的二維示意就是用這個方法畫的。

  1. 在輸入的每兩格之間插入 s − 1 個 0。
  2. 頭尾各補 k − 1 − p 個 0（有 output_padding 時，尾端再多補 op 個）。
  3. 用翻轉過的 kernel、stride 1 做一般卷積。
同一個例子：輸入 [1, 2]，kernel [1, 2, 3]，s=2，p=0

① 插 s−1 = 1 個 0：   [1, 0, 2]
② 頭尾各補 k−1−p = 2： [0, 0, 1, 0, 2, 0, 0]          ← 7 格
③ kernel 翻轉成 [3, 2, 1]，stride 1：
   [0 0 1]·[3 2 1] = 1
   [0 1 0]·[3 2 1] = 2
   [1 0 2]·[3 2 1] = 3 + 2 = 5
   [0 2 0]·[3 2 1] = 4
   [2 0 0]·[3 2 1] = 6
輸出 [1, 2, 5, 4, 6]，和蓋印章一樣

kernel 要翻轉，但權重本來就是學出來的，實際使用時不必在意。補 k − 1 − p 個 0 是為了讓印章的邊緣剛好碰到第一個輸入值；p 越大補得越少，輸出越短，這是 −2p 的另一種解釋。

反卷積示意（二維）綠色是原本的輸入，虛線是補的 0
輸入設定計算輸出
16k=4, s=2, p=115×2 − 2 + 3 + 132
7k=3, s=2, p=1, op=16×2 − 2 + 2 + 1 + 114
4k=2, s=2, p=03×2 − 0 + 1 + 18

output_padding：回到哪一個大小

卷積有 floor，所以不同的大小可能縮成同一個大小。反卷積往回放大時，就不知道該回到哪一個：

卷積 k3 s2 p1：   5 → ⌊(5+2−3)/2⌋+1 = 3
                  6 → ⌊(6+2−3)/2⌋+1 = 3

反卷積 k3 s2 p1： 3 → (3−1)×2 − 2 + 2 + 1 = 5      op = 0
                  3 → 5 + 1             = 6      op = 1

output_padding 就是用來指定要回到哪一個，它必須小於 stride。在 U-Net 這類網路，通常選讓解碼器尺寸和編碼器對齊的那個值。

棋盤格偽影：數數看每格被蓋了幾次

k=3, s=2：  1 1 2 1 2 1 2 1 1      ← 有的格子蓋 1 次、有的蓋 2 次
k=4, s=2：  1 1 2 2 2 2 2 2 1 1    ← 中間都是 2 次

被蓋比較多次的格子數值容易比較大，影像上就會出現規律的格狀紋路。k 是 s 的倍數時中間的覆蓋次數才會一樣，所以 k=4、s=2、p=1 很常用。另一個常見做法是先用最近鄰或雙線性插值放大，再接一般 3×3 卷積。上面的蓋印章示意有「覆蓋次數」這一列，可以自己試試看。

參數量

和一般卷積一樣：k² × C_in × C_out (+ C_out)。例如 128 → 64 通道、k=4：4×4×128×64 = 131,072。

每個輸入值蓋一個 kernel 印章、每次移 s 格、重疊相加；全長 (in−1)s + k，再減 2p、加 op。
12 · Fully connected & GAP

全連接與 GAP：從特徵圖到答案

全連接層（FC、Linear、Dense）的每個輸出都和每個輸入相連。接在卷積後面時，要先把 H × W × C 的立方體攤平（flatten）成長度 H·W·C 的向量。

參數量 = 輸入長度 × 輸出長度 + 輸出長度(bias) VGG16 第一個 FC：7×7×512 = 25,088 → 4,096 參數 = 25,088 × 4,096 + 4,096 = 102,764,544（約 1 億）

VGG16 全部約 1.38 億參數，光這一層就佔了七成多。這就是後來的網路改用 GAP 的主因。

做法接 1000 類的參數輸入尺寸
攤平 7×7×512 → FC25,089,000必須固定
GAP → 512 → FC513,000可以不同

Softmax：分數變機率

最後一層 FC 輸出的是每類的分數（logits），經過 softmax(zᵢ) = eᶻⁱ / Σ eᶻʲ 變成加總為 1 的機率，再和正確答案算交叉熵損失。例如分數 [2, 1, 0] 會變成約 [0.67, 0.24, 0.09]。

FC 參數 = 輸入 × 輸出；攤平會讓參數爆炸並綁死尺寸，GAP 兩個問題一起解決。

各代網路的重點

網路年份帶來的觀念
LeNet-51998卷積 + 池化 + 全連接的基本骨架
AlexNet2012ReLU、Dropout、GPU 訓練；第一層 11×11 stride 4
VGG2014全部用 3×3 疊深（就是第 04 節的道理）
GoogLeNet2014Inception 多分支；用 1×1 卷積降通道；GAP
ResNet2015殘差連接，能訓練到上百層；BN 標準化
MobileNet2017深度可分離卷積，大幅省參數

1×1 卷積：只動通道

1×1 卷積不看鄰居（感受野不變），只在同一個位置把 C_in 個通道線性組合成 C_out 個。用途是降通道或升通道，非常便宜。

256 → 64 的 1×1 卷積：1 × 1 × 256 × 64 = 16,384 個參數

殘差區塊

ResNet 讓輸入直接「抄捷徑」加到輸出：y = F(x) + x。網路只需要學「差多少」，梯度也能沿捷徑直接往回傳，所以很深也訓練得動。

256 通道進出計算參數（不含 bias）
兩層 3×32 × 9 × 256 × 2561,179,648
瓶頸 1×1 → 3×3 → 1×1256·64 + 9·64·64 + 64·25669,632

深度可分離卷積（MobileNet）

一般卷積： k² × C_in × C_out depthwise： k² × C_in ← 每個通道各自做 k×k pointwise (1×1)： C_in × C_out 例 3×3，128 → 128：147,456 vs 1,152 + 16,384 = 17,536（約 1/8）
1×1 只動通道、殘差讓網路能很深、可分離卷積拆開空間和通道來省參數。
14 · Input size at inference

推論時輸入大小不同怎麼辦

標準做法是前處理，不是靠 pooling 湊。推論的前處理要和訓練時一模一樣：

  • 縮放：例如 resize 到 256，再 center crop 224
  • 正規化：用相同的 mean / std
  • 色彩順序：RGB 或 BGR 一致；灰階要轉成 3 通道
  • 長寬比差很多：先 letterbox（補邊成正方形）再縮放，避免變形

卡住的是全連接層

卷積核是滑動的，不在意圖多大。攤平後的 FC 參數量綁死在固定長度（見第 12 節），所以有 FC 的網路才需要固定輸入。解法要在訓練前就放進架構：

方法做法
Global Average Pooling每個通道平均成 1 個值再接 FC，ResNet 這樣做
Adaptive Pooling指定輸出固定大小，例如 PyTorch AdaptiveAvgPool2d((7,7))

YOLO 為什麼能吃不同解析度

YOLO 從 v2 開始是全卷積，沒有固定尺寸的 FC。輸入變大，輸出的特徵圖格子就變多，參數完全不變。

輸入輸出格（總 stride 32）
416×41613×13
640×64020×20
832×83226×26
  • 邊長通常要是 32 的倍數，不夠會自動補邊。
  • 和訓練尺寸差太多，物體大小分布改變，準確度可能下降。
  • 同一個 batch 必須同尺寸，所以實務上仍會 letterbox。
  • YOLOv1 有 FC 層，不能隨意改尺寸。YOLOv2 還在訓練時每隔幾個 batch 隨機換尺寸（320～608）。
推論先做和訓練相同的前處理；只有全卷積或 GAP / Adaptive Pooling 的架構，才能直接吃不同大小。
15 · Train vs inference

輸入輸出、訓練與推論，需要相同嗎

輸入與輸出不必相同。空間大小可以被 stride、pooling、不補邊的卷積縮小，被反卷積放大；通道數也可以變，例如 3 通道 RGB 進、64 通道出。分類器輸入 224×224×3、輸出 1000 類分數，兩者完全不同。

訓練與推論的參數量通常相同，因為推論就是用訓練學到的同一組權重。例外：

情況訓練時推論時
輔助分類頭（GoogLeNet）額外輸出分支幫助訓練拿掉，參數變少
結構重參數化（RepVGG）3×3 + 1×1 + identity 多分支合併成單一 3×3
BatchNorm用 batch 統計、學 γ、β用 running 統計，可融合進卷積
Dropout隨機丟神經元不丟（本身沒有參數）

參數量相同不代表記憶體相同。訓練還要存每層的 activation、和參數一樣大的梯度、以及優化器狀態（Adam 多存約 2 倍參數），所以訓練吃的記憶體遠大於推論。

19 · Cheat sheet

公式速查

卷積輸出尺寸

out = ⌊(in + 2p − k′)/s⌋ + 1 k′ = d(k−1) + 1

感受野

RF = 1 + Σ dᵢ(kᵢ−1)·∏ⱼ₍ⱼ<ᵢ₎ sⱼ n 層 3×3：2n + 1

卷積參數

k² · C_in · C_out (+ C_out) 5×5: 25C² vs 2×3×3: 18C² 7×7: 49C² vs 3×3×3: 27C²

Pooling

尺寸同卷積公式 通道不變，參數 0 2×2, s2 → 減半

BatchNorm

y = γ(x − μ)/√(σ² + ε) + β 可學 2C，統計值 2C

反卷積

out = (in−1)s − 2p + d(k−1) + op + 1 k=4,s=2,p=1 → ×2

全連接

in × out + out 攤平：H·W·C

常用組合

3×3,s1,p1 → 尺寸不變 3×3,s2,p1 → 減半 3×3,s1 時 p = d 保持尺寸

省參數

1×1：C_in · C_out 可分離：k²·C_in + C_in·C_out
