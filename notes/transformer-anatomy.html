資料流只有一條主幹：token 查表成向量，加上位置資訊，進入 N 個相同的層。每一層先讓各位置互相交換資訊（注意力），再各自做一次非線性變換（FFN），兩者都包著殘差連接。最後一層輸出經線性轉換與 softmax，變成下一個 token 的機率分佈。

27,938 個矩陣怎麼數

依表中公式推算：每層有 96 個頭，每個頭各有一個 Query、Key、Value 矩陣；Output、Up、Down 每層各一個；再加上整個模型的 Embedding 與 Unembedding。

96 層 × ( 96 頭 × 3 + 3 ) + 2 = 96 × 291 + 2 = 27,938

為什麼 Query、Key、Value 各有 9,216 個矩陣

9,216 = 96 × 96：模型有 96 層，每層有 96 個注意力頭。每個頭都有自己的一組 Q、K、V 矩陣，所以 Key 矩陣有 96 × 96 = 9,216 個，Query 與 Value 也各是 9,216 個。

每個方格是一個注意力頭。橫向是同一層的 96 個頭，縱向是 96 層（第 1 層在最上面）。點選方格可以切換，亮色整列是同一層的 96 個頭。

一個頭在做什麼：每個位置的 12,288 維向量 x，分別乘上這個頭的 W_Q、W_K、W_V，各自被壓成 128 維的 q、k、v。q 與 k 的點積決定要注意哪些位置，v 則是被取用的內容。

為什麼每個頭要分開學：不同的頭負責看不同的關係，例如有的頭找代名詞指向誰，有的頭找動詞與受詞。要看不同的關係，就需要不同的投影方式，所以矩陣不能共用。這也是論文所說的多頭注意力能同時關注不同子空間的資訊。

為什麼是 128 維：12,288 ÷ 96 = 128。96 個頭各輸出 128 維，拼接後剛好又是 12,288 維，可以接著乘 Output 矩陣寫回主幹。Output 矩陣是拼接後整體乘一次，因此每層只有一個，共 96 個，不是每個頭一個。

表中沒有算進去的東西

表中的 175,181,291,520 只包含上面八類權重矩陣。論文模型中的 bias、LayerNorm 的 γ 與 β，以及位置資訊的參數都不在表內。GPT 系列使用學習式位置嵌入（GPT-3 的上下文長度為 2,048，約再增加 2,517 萬個參數），相對於總量只是零頭。

最值得記住的比例：FFN（Up + Down）約占 66%，四種注意力矩陣加起來約占 33%，兩個嵌入矩陣合計不到 1%。模型的參數主要花在每個位置獨立運算的 MLP，而不是注意力。研究界常把 MLP 視為模型儲存事實知識的主要位置，這個解讀仍在討論中。

注意力：為什麼要除以 √d_k

論文 §3.2.1 與註腳 4 · 下方為真實的隨機抽樣計算

論文假設 query 與 key 的每個分量是平均 0、變異數 1 的獨立隨機變數，則點積 q·k 的平均為 0、變異數為 d_k。d_k 越大，分數越分散，softmax 越容易被推到幾乎只剩一個位置的飽和區，梯度因此變得極小。把分數除以 √d_k 後，標準差回到約 1。

未縮放 softmax(q·k)縮放後 softmax(q·k / √d_k)

保持總計算量不變，只改頭數與每頭維度（d_k = d_v = 512 / h）。單頭比最佳設定差 0.9 BLEU，頭數太多時品質也會下降。

資料為 newstest2013 開發集上的 BLEU；長條自 24.0 起算，用來放大差異，不是從零起算。

位置編碼

論文 §3.5 · 固定的 sin / cos，沒有可學習參數

自注意力本身不知道 token 的順序，所以要把位置資訊加到嵌入上。論文用不同頻率的正弦與餘弦：偶數維用 sin，奇數維用 cos，波長由 2π 到 10000·2π 呈等比數列。選它的理由是，對任何固定的位移 k，PE(pos+k) 都能寫成 PE(pos) 的線性函數，模型因此容易學到相對位置；它也可能外插到比訓練時更長的序列。論文也試過學習式位置嵌入，結果幾乎相同（表 3 的 E 列）。

PE(pos, 2i) = sin(pos / 10000^(2i / d_model))　　PE(pos, 2i+1) = cos(pos / 10000^(2i / d_model))

橫軸是維度 i（左邊頻率高，右邊頻率低），縱軸是位置 pos。移動游標可讀取數值，暖色為正、冷色為負。
